# 澄跡智庫功能：操作說明

這個選項把《AutoCAD自動繪圖指令清單_澄跡智庫》的製圖與估量流程接到現有網頁生成器。開啟前仍使用原有模式。

## 網頁操作

1. 打開生成器，在左側輸入需求，例如「透天三層，建築物4.5×14米，四房」。
2. 展開 **澄跡智庫製圖與數量表**，勾選 **啟用清單流程（cm／1:50）**。
3. 核對基本尺寸。預設層高360、天花280、外牆20、內牆12、方柱40、門高210、窗高150、窗台90、捲門高240、浴室壁磚240，單位均為公分。窗型可選橫拉窗、上懸窗、固定窗。
4. 房間條件可先留白，由現有引擎自動安排。需要核對時，展開「指定房間淨尺寸與位置」，填樓層、室名、淨寬／深及方位。室名相同時填結果表中的房間序號。前方是圖面下方，左方是圖面左方。
5. 點 **生成平面圖**。系統會將實際牆、柱、層高與樓梯套用設定，再重新檢查。必要條件不符就停止出圖，保留前次成功圖面。
6. 在右上方圖紙頁籤切換平面、淨面積、裝修數量、柱牆表、周長明細、門窗表與各型門窗立面。多層方案保留示意剖面及南向立面。
7. 左側成果區可以展開各層明細、下載完整 JSON 或裝修數量 CSV；原有 DXF ZIP 與 PDF 下載仍可使用。ZIP 也包含計算明細與使用說明。
8. PDF 與 DXF 的 Layout1 為 **1:50**。紙張依內容選擇 A3／A2／A1／A0，超大圖採自訂尺寸。列印選 **實際大小／100%**，不要選「符合頁面」。DXF 模型空間單位為公分。

載入歷史方案會恢復當時的製圖設定與數量表。修改舊方案會沿用設定；可取消勾選，改回原有出圖方式。

## 計算依據

- 內部幾何仍為毫米。匯出才轉為公分，避免影響既有配置、碰撞檢查與法規尺寸檢查。
- 房間淨面積由房間多邊形扣除實際牆厚、柱體；保留凹角，不用外包矩形面積替代。周長封閉門窗洞口後計算，因此不扣洞口。
- 開放式客餐廳仍按引擎分區邊界分項計算；分界不代表新增加一面實牆。
- 非浴室牆面粉刷＝非浴室淨周長×層高。牆面油漆＝非浴室淨周長×天花高＋浴室淨周長×（天花高−壁磚高）。
- 浴室粉刷＝浴室淨周長×層高；浴室壁磚＝浴室淨周長×壁磚高。
- 浴室／廚房地磚採各自淨地板面積。天花及天花油漆採室內淨地板投影總和，包含車庫、浴室與樓梯區，排除天井、陽台與挑空。
- 客廳、餐廳、臥室外窗各加30cm（每側15cm）計窗簾盒，再以100/3.3cm換算台尺；面積以3.30578m²換算坪。計算保留原始精度，表格才四捨五入。
- 牆表是中心線總長，不扣門窗；同線重複段合併。陽台矮牆與電梯附屬牆不混入主牆長度。

## 製圖與已知範圍

軸線、柱、牆、窗、門、家具、室名、尺寸、數量表、門窗立面按順序產生。柱為黃底紅框、外牆黃色、內牆褐色、門窗藍色、家具紫色。柱、門窗及家具保留圖塊；牆先聯集再畫輪廓，避免交會處多餘線條。正黑體以字型名稱存於DXF；預覽時暫時使用字型檔，再還原。

門窗編號依全棟共用資料產生，包含型式、寬、高、窗台與開向；捲門另編SD。柱號依實際柱心跨層共用。平面、數量表與門窗立面均取同一份資料。平開門保留原有開向及子母門規則。

房間條件是**生成結果的核對條件**，不是任意房間拖曳或手動重畫工具。凹形房間的寬深是外包尺寸，不能冒充指定的矩形淨尺寸。尺寸容差為1cm；無法滿足時明確拒絕出圖。

柱尺寸是本次指定的製圖值，不代表完成結構計算。保留原有柱位，軸線經實際柱心；外推柱與外牆中心線可能不重合。已有的圖面、尺寸、需求、柱上下對齊檢查不因啟用此模式而略過。

既有採光檢核仍以120cm窗高計算，選項的窗高下限亦為120cm。樓梯下廁所在原資料中只有虛線註記，缺完整牆體與淨高，尚不另外估算浴室壁磚與粉刷；報告會明示，地板不重複計入。示意剖面沿用既有簡化表達，不等同逐牆剖切詳圖。

此功能輸出可編輯DXF，沒有實作AutoCAD原生指令、一次U復原或LT／Mac相容性保證。

## 本機啟動與金鑰

在專案資料夾執行：

```powershell
.venv\Scripts\python.exe -m uvicorn src.web.app:app --host 127.0.0.1 --port 8000
```

網址是 `http://127.0.0.1:8000`，只在這台電腦使用。這次功能驗證的本機沒有可用API Key；保存的離線示範可從「最近／歷史方案」載入。新的自然語言生成仍需設定原有的Gemini金鑰。變更尚未推送GitHub或部署到公開站。
