## 4. 訪談問題

1. 收到這個案例的需求後，第一個實際動作是什麼？請指出當時使用的資料。
2. 哪些資訊缺少就不能繼續？哪些可以先用假設？假設怎麼得到確認？
3. 先決定哪個空間或位置？原因是場地限制、需求、尺寸還是其他考量？
4. 這一版為什麼改成下一版？請用前後圖面說明，而不只說「不好看」。
5. 改一個需求時，還需要重新檢查哪些地方？實際用什麼方式檢查？
6. 這個案例中有沒有發生需求誤解或圖面不一致？若沒有，也要如實記錄。
7. 誰決定初稿可以接受？最低要看到哪些內容？哪些問題允許留待下一階段？
8. 哪些判斷需要現場經驗或其他專業資料，單看平面圖無法決定？

訪談原話與紀錄者解讀分開保存。先了解實際流程，再展示系統，避免用系統已有功能引導答案。
